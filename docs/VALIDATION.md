# Android 验证范围

本轮只允许 GitHub Actions 编译。本机只进行 Python 源码语法、XML/TOML/YAML 配置解析、文件结构、Git 空白检查与产物 SHA-256 核对，不运行 Kotlin 编译、Gradle、Android Lint、单元测试或模拟器。

## Actions 自动检查

- JVM 离线测试：接口模型、清单解析、称号规则、版本比较、脱敏、域名限制、并发令牌刷新、刷新失败、上传重试与 SHA-256 原子入库。
- 模拟器 API 26 / 36：模拟接口登录、令牌加密存储、五标签导航、社区详情返回、资源列表、决斗写操作取消与七次点击解锁。
- 同 debug 签名 APK 从 versionCode 1 升级到 2，验证应用私有数据保留。
- 清除模拟登录数据后检查启动画面，保存浅色/深色及 1.3 倍字体截图、测试结果与 logcat。
- 匿名真实端点诊断：只读取公告、资源清单与 Android Release，记录状态及 JSON 顶层字段，不保存正文；网络不可用不冒充契约验证通过。
- 正式 APK：四个签名 Secrets 必填，apksigner 验证签名并输出 SHA-256。

## 需要真实设备或授权账号验收

QQ 浏览器登录与返回、真实接口字段兼容性、头像与图片上传、帖子回复、购买/任务/称号操作、PVP 全流程、资源后台下载与断网恢复、进程重启恢复、SHA-256 不符阻止分享、系统文件导出、真实正式签名升级、屏幕阅读器和小屏大字体布局。

自动化使用 MockWebServer 与固定模型，不向真实服务器创建账号、购买、发帖或修改数据。真实环境是否通过不能由离线测试推断。服务器不可用与客户端契约错误需分别记录。
