# 星灯云浪 Android 界面规范

## 原生界面与信息架构

使用 Kotlin、Jetpack Compose 和 Material 3，最低 Android 8.0。一级导航固定为首页、社区、资源、服务、我的；各标签保存独立导航状态。决斗场属于服务，开发者功能属于设置。沿用应用名称和图标。

内容页使用可滚动布局；设置、编辑和服务使用标准列表、输入控件和对话框。使用系统深浅色模式、系统字体和至少 48dp 点击区域。支持大字体、多行、屏幕阅读器、系统返回及边缘到边缘的窗口内边距。

保留加载、空数据、错误及重试状态。服务端失败不得显示操作成功；提交期间禁用重复操作。发帖与回复展示正文、Markdown/HTML 图片和附件，保持图片宽高比，提供失败占位。

## 平台行为

- QQ 授权使用浏览器；应用恢复前台后继续查询结果，取消或超时后可重试。
- 决斗场仅在该页前台且处于 searching/found 时每 2 秒轮询；所有决斗写操作需确认，离开页面或后台立即停止。
- 自定义称号从目录读取单价和长度规则，显示颜色预览、可见长度与预计费用；购买前二次确认，服务端决定最终扣费。
- 资源下载由系统后台任务执行，记录持久化；校验完成前不可分享。用户通过文件选择器导出，不申请全部文件权限。
- 蜂窝设置对之后入队的任务生效；已入队任务保留其约束，界面明确说明。
- 应用更新读取 Android GitHub Releases，显示版本、说明和 APK 链接，在浏览器中下载与安装。
- 点击版本号 7 次启用开发者工具；正式 APK 也支持任意 HTTP/HTTPS 调试，自定义令牌开关默认关闭且不保存。写操作逐次确认，DELETE 需输入 DELETE。
- 诊断默认脱敏导出；原文导出再次确认。性能页每 2 秒采样，持续采样仅在应用前台运行。

## 验收与构建

验证五标签及返回状态、通知徽标、资料编辑、社区图片、下载、各服务动作、决斗轮询、开发者确认和导出。检查小屏、大字体、深浅色和 TalkBack。真实写操作仅使用专用测试数据；未联调的操作明确记录。

只通过 GitHub Actions 编译、测试与签名，不在本机安装 SDK 或执行编译。CI 缓存 Gradle 依赖、构建缓存及固定版本 SDK，密钥、用户数据和最终 APK 不进入缓存。
